# PIC16F628A Embedded Display Controller

This project demonstrates a control system using the **PIC16F628A** microcontroller. It focuses on hardware-software integration by driving an **LCD screen**, **7-segment displays**, and **LED indicators**.

## Features
- Programmed in **C** language.
- Interfaced with an LCD to display system status.
- Integrated 7-segment displays for real-time data monitoring.
- Visual status feedback via **LED indicators** for system processes.
- Developed using **MPLAB IDE** and simulated/tested on physical hardware.

## Hardware Used
- PIC16F628A Microcontroller
- 16x2 LCD Display
- Common Cathode 7-Segment Displays
- LED Array (Red/Green) for status signaling
